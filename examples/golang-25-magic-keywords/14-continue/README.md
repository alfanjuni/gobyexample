# Continue Keyword in Go

The `continue` keyword is used to skip the current iteration of a loop and move to the next one. It is useful when you want to bypass certain iterations based on a condition.

In this example, we use `continue` to skip one iteration in the loop.

---

### Running the Example

Navigate to the directory and run the following command:

```bash
go run examples/golang-25-magic-keywords/14-continue/main.go
```

# Switch Keyword in Go

The `switch` keyword is used for branching based on multiple conditions. It simplifies code when there are multiple execution paths based on different values or conditions.

In this example, we demonstrate how to use the `switch` statement to match various cases.

---

### Running the Example

Navigate to the directory and run the following command:

```bash
go run examples/golang-25-magic-keywords/08-switch/main.go
```

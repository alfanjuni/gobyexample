# Break Keyword in Go

The `break` keyword is used to exit a loop before its natural termination. It is commonly used when a specific condition is met during iteration, and you want to stop the loop early.

In this example, we use `break` to exit the loop when a condition is met.

### Running the Example

Navigate to the directory and run the following command:

```bash
go run examples/golang-25-magic-keywords/13-break/main.go
```

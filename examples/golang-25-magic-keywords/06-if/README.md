# If Keyword in Go

The `if` keyword is used to specify a conditional branch in your code. It executes the block of code within the `if` statement only if the specified condition evaluates to `true`.

In this example, we demonstrate how to use the `if` keyword to conditionally execute a block of code based on a variable's value.

---

### Running the Example

Navigate to the directory and run the following command:

```bash
go run examples/golang-25-magic-keywords/06-if/main.go
```

# Else Keyword in Go

The `else` keyword provides an alternative branch for the `if` statement. When the condition in the `if` statement is false, the `else` block gets executed.

In this example, we demonstrate how to use `else` to handle the alternative condition when an `if` condition is not met.

---

### Running the Example

Navigate to the directory and run the following command:

```bash
go run examples/golang-25-magic-keywords/07-else/main.go
```

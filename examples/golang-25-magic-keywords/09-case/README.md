# Case Keyword in Go

The `case` keyword is used to define individual branches within a `switch` statement. Each `case` compares the value in the `switch` statement to a constant or condition.

In this example, we demonstrate how to use `case` to handle specific conditions in a `switch` statement.

---

### Running the Example

Navigate to the directory and run the following command:

```bash
go run examples/golang-25-magic-keywords/109-case/main.go
```

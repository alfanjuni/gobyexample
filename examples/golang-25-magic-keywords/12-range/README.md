# Range Keyword in Go

The `range` keyword is used to iterate over elements of arrays, slices, maps, or channels. It provides both the index and the value of each element. It is particularly useful for traversing data structures in a clean and concise way.

In this example, we iterate over a slice of numbers using `range`.

---

### Running the Example

Navigate to the directory and run the following command:

```bash
go run examples/golang-25-magic-keywords/12-range/main.go
```

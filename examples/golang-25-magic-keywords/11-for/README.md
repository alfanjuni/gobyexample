# For Loop in Go

The `for` loop is the only looping construct in Go. It is highly flexible and can be used in multiple forms, such as traditional loops, conditional loops, and infinite loops. Go doesn’t have `while` or `do-while` loops because `for` can handle all types of iterations.

In this example, we demonstrate a simple `for` loop that iterates a specified number of times.

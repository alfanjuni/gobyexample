# Goto Keyword in Go

The `goto` keyword is used to jump to a labeled statement within a function. Though it should be used sparingly due to its potential to make code harder to read, `goto` can be useful in certain scenarios like breaking out of nested loops or early function exits.

In this example, we demonstrate how to use `goto` to jump to a labeled statement within a function.

---

### Running the Example

Navigate to the directory and run the following command:

```bash
go run examples/golang-25-magic-keywords/10-goto/main.go
```
